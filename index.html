lograilUniversal logging for Web, Node.js & Electron

High-performance, structured logging with a layered Core → Pipeline → Transport architecture that runs unchanged on Web, Node.js and Electron — and extends to other platforms through plugins.

Get Started
API Reference
View on GitHub

Runtime agnostic

One API for Web, Node.js and Electron. The runtime adapter is auto-detected, or you can pass your own.

Structured by default

Every entry is a typed LogEntry with timestamp, scope, context, metadata and full Error cause chains.

Pluggable pipeline

Filters, processors and formatters compose freely. Redaction and sampling ship out of the box.

First-class runtimes

Web, Node.js and Electron are supported out of the box with auto-detected adapters — one API, no per-platform code.

Extensible via plugins

Plugins add transports, reshape the pipeline, intercept entries and register other plugins at runtime. Bring your own runtime adapter to support any other platform.

Tiny & typed

Written in TypeScript, ESM + CJS dual build, MIT licensed, with subpath exports for tree-shaking.

Per-transport routing

Each transport can set its own level and formatter, so one logger fans out — e.g. errors to OTLP, everything to a file.

Observability built in

Ship logs to an OpenTelemetry Collector via OTLP with traceId/spanId correlation, plus child loggers and sampling for cost control.

Crash-safe

Flush on exit, capture uncaught errors as fatal, and bridge console.* into the structured pipeline.
